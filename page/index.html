the point of the app

concat

drop files in, drag them into order, export one file. sort by name numerically (so track2 lands before track10, which is more than some paid tools manage), or shuffle the whole list if you're building a mix.

  • gap or crossfade at any join; the total length updates as you change it
  • loudness matching that levels each file toward the median of the set, not the loudest one
  • preview a single file, or the whole joined sequence
  • with the mastering chain off, files are joined exactly as they are. no quiet re-mastering.
when you need control

timeline

multitrack editing for when files have to overlap or a single clip needs its own treatment. clips on tracks, trim, split, fades, volume, pan.

  • parametric eq with draggable nodes, plus compression and a true-peak limiter
  • an a/b button that routes playback around the chain, so you can hear what it's doing
  • waveforms sharpen as you zoom; the canvas only ever draws the visible window
  • snapping to bars, beats and clip edges, which you can switch off

tags

the part everything else gets wrong

exporting a joined file and then hunting for a separate tag editor is a silly way to spend an evening. it's built in, and it writes to every format.

  • title, artist, album, year, track and disc numbers, genre, comment, composer
  • isrc, bpm, initial key, lyrics, copyright, publisher, encoder
  • embedded cover art, dragged in or pasted
  • tags are read out of imported files too, so you can start from what's already there

vorbis comments for flac, id3v2 for mp3 and wav. you can also edit tags from inside the export dialog, which is where you usually remember you forgot.

in and out

formats

decoding, mixing and encoding all happen in rust. nothing is shelled out to ffmpeg, so there's no second binary to install.

import

wav · mp3 · flac · ogg · aac · m4a · aiff

native picker, or drag files anywhere onto the window. they appear straight away and the waveforms fill in behind you.

export

wav16-bit, 24-bit, 32-bit float
flac16 or 24-bit; fast / balanced / maximum
mp3cbr 128–320, or vbr v0–v9

tpdf dither where it applies, and it's disabled where it doesn't rather than left on as decoration.

what happens to the audio, precisely
  • sources are decoded once and cached by path, so ten clips on one file cost one decode
  • resampling is a windowed-sinc filter (32 taps, 4096 phases), measured at −89 dBFS reconstruction error; a 20 khz tone downsampled to 22.05 khz comes back 82 dB down instead of folding into the audible band the way linear interpolation does
  • crossfades and panning are equal-power, so a centred track stays at the level you set
  • loudness is measured with itu-r bs.1770 k-weighting
  • join two files with unity gain, no crossfade and the chain off, and the output is your audio placed back to back. that's the whole promise.

about that warning

these builds aren't code-signed, so windows shows "windows protected your pc" the first time you run one. click more info, then run anyway.

the honest reason is that a signing certificate costs a few hundred pounds a year and has to live on a hardware token, which is a lot of ceremony for a tool that joins wav files. it's on the list; it isn't done.

keys

worth learning four of these

spaceplay or pause whichever view you're looking at
←→scrub 5s; ctrl for 15s, alt for 30s
ctrlssave, straight to the current file after the first time
ssplit the selected clip at the playhead
ctrlzundo, across both workspaces
right-clickcontext menu, in either workspace

auto-save runs every five minutes, but only over a file you've already chosen. it will never invent a filename or interrupt you with a dialog.
